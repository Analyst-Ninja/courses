Inheritance
1. Single Level Inheritance
   - A ---> a
2. Multi Level Inheritance  
   - A ---> a ---> a'
3. Hierarchical Inheritance
   - A ---> a and A ---> b
4. Hybrid Inheritance
   - A ---> a ---> a' and A ---> b 

There is another type of inheritance in C++, but that is available in form of interfaces
